# Purpose

This document provides real-world request and response examples for the REST APIs defined in `08_API_Design.md`.

It serves as a reference for frontend developers, backend developers, testers, and API consumers.

---

# Conventions

Base URL

```
/api/v1
```

Authentication

```
Authorization: Bearer <access_token>
```

Content Type

```
application/json
```

# Authentication APIs

## Register

### Request

```http
POST /api/v1/auth/register
```

```json
{
  "full_name": "Raj Garudkar",
  "email": "raj@example.com",
  "password": "StrongPassword123"
}
```

### Response

```json
{
  "success": true,
  "message": "Account created successfully.",
  "data": {
    "id": "usr_001",
    "email": "raj@example.com"
  }
}
```

---

# Notes

- All endpoints return JSON.
- All timestamps use ISO 8601 format.
- UUIDs shown are sample values.
- Protected endpoints require a valid JWT access token.
- OCR only suggests values; users must verify before financial records are updated.
- Soft-deleted records are excluded from normal API responses.
